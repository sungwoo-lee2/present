# 모임 발표자료 생성기

주제와 분석 내용을 입력하면 16:9, 10장짜리 편집 가능한 PPTX를 내려받습니다. 초안은 이 브라우저에 자동 저장되며 JSON 파일로 백업하고 다시 열 수 있습니다. 발표 내용을 서버 DB에 저장하지 않습니다.

## 실행

Node.js 20 이상에서 `npm install`, `npm start` 후 `http://localhost:3000`을 엽니다. Render에서는 GitHub에 압축을 푼 파일을 올리고 Web Service를 생성합니다. `render.yaml` 또는 Node 서비스 설정(`npm install`, `npm start`)을 사용하세요.

KRX 종가 자동 채우기를 사용하려면 Render Environment에 `KRX_API_KEY`를 설정하고 KRX Open API에서 유가증권 및 코스닥 **일별매매정보** 서비스 이용 승인을 받아야 합니다. 키를 GitHub에 올리지 마세요. 인증키가 없더라도 출처·기준일을 입력하여 PPTX를 만들 수 있습니다. 실시간 시세, 외국인·기관 수급, 뉴스 해석은 자동 생성하지 않습니다. KRX 오류가 나면 숫자를 보여주지 않습니다.

가격을 입력하면 기준일과 출처도 요구합니다. 자동 조회 시 KRX 일별 데이터 기준일을 붙입니다. 발표 전에 원본 데이터와 수치를 대조하세요. 등록한 근거와 판단만 슬라이드에 들어가며 비어 있는 영역은 입력 필요로 표시됩니다.

## 참고

이 앱은 기존 주식모임 연구소와 별도 서비스입니다. 기존 앱의 DB 기록을 자동으로 읽거나 옮기지 않습니다. 브라우저 초안은 해당 PC·브라우저에 저장되므로 JSON 초안도 보관하세요. 누구나 접근 가능한 배포에서는 주제 및 회원 개인정보 입력에 주의하세요.
